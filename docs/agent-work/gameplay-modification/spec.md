# 探索、防詐與資產養成：實作規格

狀態：使用者已授權 AGY 實作。2026-09-18。
專案：C:\Users\kun\.gemini\antigravity\scratch\antifraud_game
分支：feature/gameplay-modification；起點 ca8c909。

## 目標
將提示答案的閱讀測驗，改為有限資訊下的查證與決策；將快測收入、章節成長、首次購屋任務與可見資產成果接成可玩的閉環。保留原有玩法和帳號資產。繁體中文玩家介面。
本次實作第一個完整版本，不宣稱所有真實法律或交易情境均受涵蓋。不得部署、推送、提交或操作正式資料庫。

## 已決定的設計
- 不再於作答前提供結局、警方定性、詐騙分類、難度星數、話術正解或暗示性標題。
- 案例事實與真相由伺服器固定；AI 只演繹對話，不決定真相、查證結果、獎勵或法規。
- 主動查證要有效：資訊先不完整，玩家選擇追問、查看自己的紀錄、比對資料、走獨立官方入口。不同動作會揭露預先固定的資訊。
- 保留新手的可選程序提示與事後教學，不讓刪除提示變成盲猜。充分證據出現後可提早結束。
- 允許安全暫停/退出，不必靠危險互動才能拿獎。合法/可疑/資訊不足的情境皆存在。
- 不按回合數、點擊數發錢；依有效且不重複的查證、決策發獎。全檢舉不能得到完整獎勵。
- 房產與車輛有可見擁有狀態、用途和內容；第一間房設短交易任務，重複購屋不重考。裝飾直接購買。
- 第一版沒有排行、多人系統、真正電話/銀行串接、付費抽獎或強制每日連續登入懲罰。

## T1：有限資訊的題目與內容
維持 game_cases 的管線邊界，不能直接修改或破壞線上策展表。建立明確、可測試的玩家可見素材投影/策展覆蓋，涵蓋五類；缺少安全投影的歷史案例不得把完整結局當題面。禁止用脆弱字串截斷假裝完成策展。
快測一輪仍為五題，至少納入下一步查證或證據能證明什麼的題型。可保留真偽判斷，話術辨識/配對移為明確標示的教學練習或事後解析，不再主導實戰。
滑卡保留輕量操作與回饋，使用當下訊息，不顯示揭底來源標籤。支援資訊不足時進一步查證或安全略過的明確選擇；不把所有資訊不足一律當正常或詐騙。
首答與結算伺服器權威：quiz 保留現有防重放、不可變發牌與判分；swipe 增加同等的一次性場次/首次作答防重放後才提高獎勵。
所有正解、隱藏身分和未解鎖證據不能混在公開 payload、HTML data-* 或客戶端常數中。

## T2：情境探索
五種既有 fraud_type 都有固定的初始公開情境與合理合法對照；同類真假開場不能成為固定答案指紋。
加入伺服器持久化的可用查證動作及已取得證據。例如自己的訂單紀錄、對方提供的文件、獨立客服查證。至少兩種不同證據來源，不把對方自稱官方當獨立證據。
玩家自由文字與查證工具並存。工具有合理事實內容而非直接顯示「詐騙=true」；同一動作重複不能刷獎。
AI instructions 注入目前可知事實與已揭露狀態；不得為拖延遊戲改變已確定事實，不得編真實法條或揭漏未取得證據。固定世界狀態與工具結果不依賴 LLM。
增加 safe_exit 終局；在適當查證後選擇正式管道完成也可成功。先保持 report/comply 舊資料可讀，新評分依證據與動作，不要求固定聊天次數。
每場報酬範圍、風險金額在作出承諾前清楚可見。正常安全退出不受罰。一般受騙最大損失先設 2000，誤判懲罰最多 250；不得扣除整體房產或造成數十輪還債。
每場有效查證後正確裁決基礎現金最多 1200（章節 multiplier 適用），盲猜不超過 100；安全退出不提供可刷取的無條件現金。合理查證的回饋用證據與安全處置文字呈現，不鼓勵和可疑對象長聊。
保留每日上限、所有權檢查、AI 失敗不扣回合。send、judge、tool 並發與重試不得覆寫對話、重複結算或超過上限；鎖順序 session -> user。

## T3：收入與章節
以五題平均四題正確約 1000 為設計基準：每正確題基礎 240，現金依既有連對每3題+10%公式取整，XP 保留每題20。五題全對1320、四題且最佳連對3為1056；不能宣稱實測平均1000。
滑卡相同實際時間的收入不應明顯優於快測，先每正確100，保留連對加成；safe skip 無現金，場次一次性。
收入倍率 = 1.15 ^ min(已完成章節數, 5)，向下取整，最高約2.011倍。只作用主動訓練/情境獎勵，不放大買賣、初始補助或租金。
章節是真正的可持久化里程碑：每章完成至少一輪訓練及該章的一次有證據的情境任務；五章分別覆蓋五類查證技能。每個 session 最多推進一章，不以同一筆歷史紀錄瞬間完成五章。
首頁展示目前章節、條件、進度、下一個用途；移除虛假今日挑戰+500和不可用的排行榜/每日訓練解鎖承諾。登入後能自然找到玩法与目標。
新玩家現金仍1000；一次性入門章節補助7000，server-authoritative 記錄防重複。現有玩家也只能透過完成該章領一次，不能 migration 反覆補發。

## T4：資產、首次購屋與可見成果
房產六階價格暫定 20000/36000/65000/117000/210000/380000；每日收益先200/360/650/1170/2100/3800。這是遊戲內數值，不是真實投資收益；10-20%被動收入占比是待驗證目標，不能宣稱所有玩家皆滿足。
每天租金按完整24h累積，離線最多3日須真正截斷，重複讀取不可把超過3日的舊期間反覆領完；購買當下不能追溯獲得持有前租金。
新舊房產必須有安全相容策略：保存購買成本，回收按實付60%，資產估值策略清楚且不讓舊房突然能按新價套利；migration 不抹除既有現金/所有權。
第一間房先選物件，再進交易事件，2-3個有意義查證動作，目標2-4分鐘。不額外收任務費。至少一組正常與可疑的可策展交易變體；可疑交易被識破後算通過查證任務，可改走官方交易渠道完成同一購屋目標，不扣掉購屋款。
通過任務不是純前端 flag；buy endpoint 檢查伺服器任務資格、現金、等級，任務重試/刷新可恢復，重複購買請求有防重送，扣款與建立資產原子化。
已有房產的舊玩家不被迫重做首次任務。後續同類房產直接購買；後端不可被任意 submitted task_id 繞過。
資產頁新增「我的家」可視覺呈現與至少3種可選裝飾（500/1000/2000），裝備/佈置可保存且不是只有靜態待開發文字。首房購得後有完成畫面與實際解鎖的一個後續生活查證事件，形成閉環。
至少一種車輛資產（60000）有可見展示與一個車輛交易/維修相關的後續事件入口；避免建立大型3D/地圖系統。基礎查證工具不因買房/車而鎖住。
查證教材、模擬紀錄與程序資訊不冒充真實法規建議；有實際法律敘述必須附官方來源及查核日期。第一版優先通用身分、授權、文件、付款對象一致性。

針對新規則、首答、重試、並發、所有權、章節一次性、購屋門檻、租金/成本相容寫實質測試。
跑 backend unit、前端 unit/build，環境可行時跑新增 API integration（獨立測試DB，禁止正式DB）。以 TestModel 或固定 stub 驗 AI 編排，不冒充真實Gemini驗證。
提供可實際檢視的新UI證據；若缺本機 DB/AI 金鑰，清楚標註阻礙，允許隔離的本機測試環境，不得往正式域名造資料或改帳號。
更新 README/玩法說明，清楚区分實作與未驗證的遊玩時長假設。

## 驗收清單
- AC1：作答前無結局、類別提示與隱藏答案；五類都有安全可見素材。
- AC2：查證前後資訊不同，兩個來源可比對；相同動作重送不刷獎，安全退出有效。
- AC3：真相固定，LLM不裁決；AI失敗不消耗進度；情境重試/並發只結算一次。
- AC4：五題全對基礎1320，章節倍率15%最多五階；任務與補助只算一次。
- AC5：滑卡需首次答案/一次性場次，重放不能增現金或XP。
- AC6：首房未完成查證不能直接API購買；識破假交易後可正常購得；刷新可恢復。
- AC7：舊玩家現金/資產保留、原價回收不套利、離線3日上限有效、購前不生租金。
- AC8：購屋有可見家園成果、三種可保存裝飾、後續事件；車輛有可購與可玩的用途。
- AC9：章節入口替代假占位，所有新操作有載入/錯誤/重試狀態，手機版可操作。
- AC10：SDK/遷移/文件一致，測試與build有實際命令、結果與未驗證項；不部署不提交。
