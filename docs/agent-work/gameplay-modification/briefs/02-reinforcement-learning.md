# 使用者追加：融入強化學習概念

使用者在第一個AGY作業進行時追加「想融入強化學習的概念」。這是原目標延伸，不取消第一版。待 implement-mu6a4mey-4cb1da6b 完成後，使用同一conversation continue派工，先檢視第一版已涵蓋部分，只補缺口。

## 定位
以玩家為學習者，建立 observation -> action -> consequence -> reflection 的策略學習。這是採用強化學習概念的遊戲設計，不宣稱人類學習等同機器RL，也不宣稱已訓練DQN/PPO或具備實證個人化成效。第一版不需ML訓練服務。

## 需要實作的行為
1. 固定事件世界狀態/真相，玩家只能看到目前 observation。對話及查證action導致可持久化的新觀察，安全退出/正式渠道完成為合法終局。
2. 伺服器記錄action ledger，至少含動作、取得證據ID、是否新資訊、終局處置。不記/暴露客戶端可讀的未揭露真相。避免存重複自由文字而無用途。
3. reward 設計不鼓勵刷行為：有效新證據僅一次計分，並非每次工具點擊都給錢；聊天長度不加分。有效獨立查證與有證據的合理處置得到較高終局評價。幸運盲猜與充分查證要有區別。安全退出不能為了低獎勵而被視為錯誤。
4. 不把「取得越多線索」永遠當更好。玩家已充分驗證後立刻完成應可得完整評價；發現高風險時停止不需要為了滿分繼續周旋。至少一個替代證據路徑也能成功，而非僅固定按鈕順序。
5. 終局呈現簡短行動回顧：你做了什麼、哪個結果支持/不支持判斷、下一次可改進哪一步；只回顧既有ledger與策展規則，不讓LLM編造使用者做過的事。隱藏事實只有結束後才能揭曉。
6. 間隔後重新遇到同一技能但不同敘事/合法對照，不能只重發相同答案；可先用確定性技能練習安排（記錄近期已完成案例、避免立即重複）實作。資料不足時明確降級，不能稱個人化RL。
7. 章節條件依有效策略行為，而非只按答對次數；維持一次性結算與原經濟數值。不要為追加概念再無條件增加獎金。

## 驗收 RL1-RL5
- RL1：同一查證動作重送不加新證據分或現金。
- RL2：相同正確終局，盲猜與有證據路徑的評價有合理差異。
- RL3：安全退出不扣錢；充分證據後提早結束可得完整評價。
- RL4：兩條有效證據路徑都可完成，回顧準確對應本人action ledger，刷新可恢復。
- RL5：近期案例不立即重複（素材足夠時），不同敘事練同技能；前後端文案不冒稱ML或保證學習成效。
