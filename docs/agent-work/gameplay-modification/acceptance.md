# Codex 驗收情境

最終報告收取前不檢查 AGY 中途修改。以下為預先確定的驗收，不代表測試已通過。

## 核心路徑
1. 新玩家1000現金 -> 完成一輪快測 -> 得到可解釋的逐題回饋與一次性報酬。
2. 同一快測/滑卡session重送結算，不增加現金、XP或章節進度。
3. 情境初始畫面/網路payload無persona_role、完整證據、分類與結局。查看自己的紀錄、獨立查證各給固定結果；刷新結果不變。
4. 有證據正確處置、無證據盲猜、安全退出三路徑得分不同；安全退出不扣現金，不強迫付款或多聊。
5. 一輪訓練和目前章節指定情境完成後，章節最多推進一次，補助最多一次。歷史同場不得在重送時滿足下一章。
6. 首房選擇 -> 收到交易 -> 查證 -> 正常完成，現金原子扣除且新增一筆房產。另一分支識破可疑交易後仍能保留資金並走正式交易。
7. 未通過任務直接買房、他人任務ID、刷新重送、雙擊購買，皆不能繞過資格或重複扣款。
8. 房產展示 -> 購買裝飾 -> 佈置 -> 刷新仍保留 -> 打開解鎖生活事件。車輛用途有實際事件入口。
9. 舊房產升級後按原實付成本變賣；30天離線只能獲取最近上限3日，不因重複read/claim多拿；購房前時間不算租金。
10. 手機畫面可操作：題目、證據、查證工具、退出、錯誤重試、購屋與佈置皆不被底部導覽遮擋。

## 數值預期
- quiz 5 correct/best streak5 -> 1320基礎現金與100XP。
- quiz 4 correct/best streak3 -> 1056基礎現金。
- 章節倍率0/1/5/6 -> 1/1.15/約2.011/仍約2.011；整數金額計算規則一致。
- 7000一次性入門補助不能被並發/重送重複領取。
- 買房、租金、變賣與補助不乘主動收入倍率。
