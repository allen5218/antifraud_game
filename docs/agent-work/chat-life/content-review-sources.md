# 首輪內容驗收補充來源

Codex 2026-09-20 查閱官方搜尋結果，用於驗收 R7；不代表遊戲已串接官方查詢、不代表原創故事是真實案件。此筆記在第二輪派工後新增，後續驗收使用。

- 消防署《消防機關實施消防安全檢查絕不會推銷消防安全設備》：檢查不符規定會依法開立通知，由管理權人自行委託專業廠商；檢查人員不推銷設備或介紹特定廠商。https://www.nfa.gov.tw/pro/index.php?article_id=4051&code=list&flag=detail&ids=113
  - 驗收含義：不能把假冒機關催購的報案直接判為錯誤，不能無依據斷言必然僅民事爭議。判斷應看具體證據與處置目標。
- 衛福部《公益勸募管理系統優化，勸募活動資訊更透明》：捐款前可核對主管機關許可文號與有效勸募期間。https://dep.mohw.gov.tw/dosaasw/fp-530-80071-103.html
  - 驗收含義：慈善演出故事不能用虛構文化部核准函當作所有募款行為合法的充分證明；故事模擬欄位應分別比對活動、對象、期間與收款用途，不憑桌牌或人物身份判斷。
- 警政署刑事警察局《租屋季慎防假房東 寄鑰匙、帳戶認證全是詐騙話術》：現場看屋、核對身分；物流不會以實名認證要求匯款操作網銀。https://www.cib.npa.gov.tw/ch/app/news/view?id=1887&module=news&serno=49cbf0a6-1d97-40f0-8fc7-21c4f35936fa
  - 驗收含義：住宅/車輛分支提供接觸資料或到訪機會，不直接等於證据充分，仍要查核出租權限及收款對象。
