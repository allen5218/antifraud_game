# 情境對抗的劇本與人格

新版情境對抗的內容資料。系統在玩家遊玩中隨機分配事件（手機推播），每次各自隨機抽一個**劇本**和一個**人格**：劇本決定對方是誰、要什麼、怎麼交鋒；人格決定對方怎麼說話。AI 看得到玩家名字和目前財產，照劇本盯上某項財產。

**是不是詐騙由劇本的 `role` 決定，結果由玩家按的動作卡決定，AI 不判分。**

檢查：`cd backend && uv run pytest tests/unit/test_content_scenarios.py -v`

## 劇本 `scripts/<key>.md`

key 是 `<role>-<fraud_type>-<三位數>`，例如 `scam-atm-001`、`legit-investment-003`，和檔名一樣。

| 欄位 | 內容 |
|------|------|
| `key` | 同檔名 |
| `title` | 短標題（15 字內） |
| `role` | `scam`（詐騙）或 `legit`（正當） |
| `fraud_type` | `investment`、`fake-sale`、`shopping`、`romance`、`atm`、`other`；正當劇本填它外觀上像哪一類 |
| `channel` | `line`、`sms`、`phone`、`fb`、`ig`、`dating`、`marketplace`、`email` |
| `opening` | 對方傳來的第一句話 |
| `target_assets` | 盯上的財產：`cash`（現金）、`savings`（存款）、`property`（房產）、`card`（信用卡或金融卡）、`otp`（簡訊驗證碼）、`account`（網銀或平台帳號）、`personal_data`（個資） |
| `actions` | AI 可以丟給玩家按的動作卡，意思見下方「動作卡」 |
| `tactics` | 用到的話術（`time_pressure`、`authority`、`greed`、`social_proof`、`trust_building`），詐騙至少一種；正當的對方也可能催你或說很多人在用，照實填 |
| `benefit` | 只有正當劇本有：玩家接受後真的拿到什麼。投資商品一定要寫會漲跌 |
| `clues` | 線索，至少四條，每條寫成「地點：看到什麼」，例如「購物：這筆訂單寫著一次付清，沒有分期」。地點見下方。詐騙的線索會讓它穿幫，正當的線索會證實它是真的 |
| `trap` | 只有詐騙劇本有：玩家用對方給的管道查（對方給的電話、連結、客服帳號、通話中按 165）會看到什麼，寫成「管道：看到什麼」。接起來的都是同夥，會說「沒錯，請照做」 |
| `elder_ok` | 能不能改成電話來電給長輩 |
| `sources` | 新聞與詳細經過的網址；詐騙至少兩個 |

本文段落依序是：

- `## 背景`：真實經過，用自己的話寫，不寫當事人姓名或姓氏
- `## 階段`：`### 開場`、`### 建立信任`、`### 提出要求`、`### 施壓`、`### 收割`（正當劇本是 `### 成交`），每階段 2～3 句「」括起來的示範台詞，要提到玩家的財產。台詞裡的金額、房子、地址是例子，AI 要換成玩家實際的。台詞不寫對方的姓名和性別，那是人格決定的；稱呼玩家一律用「你」或「您」，不用「妳、哥哥、兄弟、老婆」這類會假設玩家性別的詞
- `## 破綻`（詐騙）或 `## 為什麼是真的`（正當）
- `## 玩家反應`：`### 懷疑時`、`### 要求查證時`、`### 拒絕時`

### 動作卡

| 代碼 | 玩家按下去的意思 |
|------|------|
| `transfer_cash` | 把錢付給對方：匯款、轉帳、無卡提款、面交現金、照指示在提款機操作 |
| `transfer_property` | 把房產交出去：過戶、拿房子去抵押或增貸再把錢交給對方 |
| `give_otp` | 把手機收到的驗證碼告訴對方 |
| `give_card` | 交出卡片：念卡號和背面三碼、寄出提款卡和密碼 |
| `click_link` | 點對方給的連結、掃對方給的條碼 |
| `install_app` | 照對方的連結下載程式 |
| `add_friend` | 加對方給的 LINE 帳號、進群組 |
| `buy_product` | 向對方買東西或金融商品 |
| `rent_out` | 把房子租給對方 |
| `sell_property` | 把自己的房產或物品賣給對方 |
| `accept_refund` | 收下對方給的錢：退款、還款、獎金、發還的款項 |

詐騙劇本裡，按下會讓財產流到對方手上的卡（付錢、交房、給驗證碼或卡片）就會被騙走；正當劇本裡，按下成交的那張卡（`rent_out`、`sell_property`、`buy_product`、`accept_refund`、`transfer_cash`）就拿到 `benefit` 寫的好處。`legit-other-011`（警示帳戶剩餘款發還）適合在玩家被騙、打過 165 之後才出現。

### 線索怎麼用

查證像解謎遊戲：對話畫面有一個「我的手機」，裡面每次都是同樣幾個地方，線索藏在哪裡看不出來，沒放線索的地方照常顯示平常的內容，不標「這是線索」。每次事件從四條裡隨機放兩條，加上對方在對話裡自己露出的破綻，玩家漏看一些也還推得出來。結算時告訴玩家藏了哪些、漏了哪些。

自己找的管道看得到真相；用對方給的管道查，詐騙會被同夥接起來（`trap`）。這是要練 165 教的「一聽、二掛、三查證」：掛掉之後自己找電話查，不要用對方給的。

| 地點 | 裡面有什麼 | 年長者模式 |
|------|------|------|
| `來電紀錄` | 剛才來電的號碼 | |
| `通訊錄` | 打給本人、家人或朋友 | 打給孩子 |
| `瀏覽器` | 官網、金管會、實價登錄、圖片搜尋 | |
| `銀行` | 銀行或證券的官方程式：交易紀錄、卡片狀態 | |
| `購物` | 購物程式的訂單頁 | |
| `錢包` | 信用卡、金融卡（背面有客服電話）、收據、合約 | 看卡片背面 |
| `新聞` | 新聞報導 | |
| `165` | 掛掉之後打 165 問到的一般說法，不會直接說這次是不是詐騙 | 打 165 |
| `對話` | 點開對方傳的網址、照片、大頭貼看細節 | |

年長者模式不翻程式：來電按「掛掉」後，吉祥物給幾個大按鈕（右欄），按了用台語念出那條線索。

## 人格 `personas/<key>.md`

人格只寫說話方式和個性，**不寫騙術、任務或要對方做的事**，因為同一個人格要能演詐騙也要能演正當的角色。示範句寫日常的話。

| 欄位 | 內容 |
|------|------|
| `key` | 小寫英文加連字號，同檔名 |
| `name` | 顯示名稱 |
| `age`、`gender` | 數字；`男` 或 `女` |
| `speech_style` | 一句話說明講話的樣子 |
| `typing_habit` | 標點、錯字、貼圖或表情符號的習慣 |
| `temperament` | 個性 |
| `when_doubted` | 被懷疑時的反應 |

本文段落依序是 `## 說話方式`、`## 口頭禪`、`## 示範句`（至少 5 句）。角色打的表情符號是模擬真實對話，可以有。參考來源記在 `personas/SOURCES.md`。

## 寫法

白話中文，中文旁用全形標點，不用破折號、AI 腔與公文用語（規則和題庫管線一樣）。這是公開倉庫，不放當事人個資。
